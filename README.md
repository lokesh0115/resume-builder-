# Mini Resume Builder

A front-end web app to create a clean one-page resume. Fill in a form, see a live preview, pick a template and colour, add a photo, and save it as a PDF.

**Live demo:** https://lokesh0115.github.io/resume-builder-/

## Features
- Live resume preview while you type
- Sections: basics, summary, skills, education, internships, projects, certifications, extra-curricular activities, hobbies and interests
- Add or remove multiple entries in each list section
- Photo upload (cropped to a passport-style portrait, stays on your device)
- 6 templates: Classic, Modern, Minimal, Elegant, Compact, Sidebar, plus an accent colour picker
- One-page A4 check with a warning when content is too long
- Save as PDF (browser print)
- Data saved in the browser (localStorage) with a Reset button
- Works on mobile and desktop

## Tech used
HTML5, CSS3, JavaScript, localStorage, Git, GitHub Pages

## How to run
1. Download `index.html`.
2. Open it in any browser (Chrome, Safari, Edge). No installation or server is needed.
